**CTRLMCP** is a turnkey, production-grade [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) server running with full `root` privileges on Ubuntu. It transforms your VPS or dedicated cloud server into an AI-controllable infrastructure powerhouse.

Equipped with **23 administrative tools**, automated **Let's Encrypt SSL/TLS**, **Nginx reverse proxy**, **256-bit Bearer token authentication**, and native support for both **Claude Web (`claude.ai`) Custom Connectors** and **Claude Desktop / Cursor**.

## 🌟 Key Features

* ⚡ **Turnkey One-Line Deployment:** Automatic setup of Python venv, MCP SDK, systemd service, Nginx reverse proxy, and Let's Encrypt SSL.
* 🛡️ **Dual-Layer Security:** Protected by Let's Encrypt HTTPS encryption and an autogenerated 64-character (256-bit) Bearer token stored in a `600 root-only` file.
* 🌐 **Full Claude Web Support:** Seamlessly integrates with Claude Web Custom Connectors using URL-based token query parameters (`?token=<TOKEN>`) and CORS preflight handling.
* 💻 **Claude Desktop & Cursor Ready:** Supports standard HTTP `Authorization: Bearer <TOKEN>` headers out-of-the-box.
* 🛠️ **23 System Tools:** Execute root commands, inspect memory, monitor disks, manage systemd services, inspect Docker, check open ports, tail system logs, manage crontabs, and more.
* 🔄 **Persistent & Resilient:** Runs as a systemd service (`ctrlmcp.service`) with auto-start on boot and auto-restart upon failure.
* 🧪 **12 Automated Self-Tests:** Built-in verification script validates Python syntax, local socket, JSON-RPC initialize, tools list, 401 unauthorized rejection, and 200 authorized success.
* 📟 **Interactive CLI Tool:** Manage your MCP server anytime by typing `CTRLMCP` or `ctrlmcp` in your terminal.

## 🚀 Quick Start (One-Liner Install)

Run the following command on your Ubuntu server as `root`:

```bash
curl -fsSL https://raw.githubusercontent.com/ahmadElsharawy/CTRLMCP/main/install.sh | sudo bash
```

### What the installer does:
1. **Validates OS & Architecture:** Supports Ubuntu 20.04, 22.04, 24.04 LTS (x86_64 & aarch64).
2. **Prompts for Parameters:**
   - **Internal Port:** Automatic `8420` (internal ASGI server, auto-selects next available port if occupied).
   - **External HTTPS Port:** Default `443` (or choose a custom external port like `8443`, `9443`).
   - **Domain Name:** e.g., `mcp.yourdomain.com` (automatically resolves DNS against your server's public IP).
   - **SSL Email:** Optional contact email for Let's Encrypt renewal notices (or skip).
3. **Installs System Dependencies:** Installs Python 3, `python3-venv`, Nginx, Certbot, UFW, and networking tools.
4. **Generates Secure Bearer Token:** Creates a random 64-character hex token in `/etc/ctrlmcp/token`.
5. **Configures & Starts Systemd Service:** Generates and enables `ctrlmcp.service`.
6. **Configures Nginx & Obtains SSL:** Configures reverse proxy on the specified HTTPS port and acquires an official Let's Encrypt SSL certificate.
7. **Runs 12 Automated Verification Tests:** Confirms the entire stack is operational before concluding.
8. **Installs Management CLI & Launches Dashboard:** Creates `/usr/local/bin/CTRLMCP` and immediately launches the interactive dashboard.

## 🔌 How to Connect

### 1. Claude Web (`claude.ai` Custom Connectors)

1. Open **Claude.ai** → Click your profile icon → **Customize** → **Connectors**.
2. Click **"+"** or **"Add custom connector"**.
3. Fill in the connection form:
   - **Name:** `My Ubuntu Server`
   - **URL:**
     ```text
     https://<your-domain>/mcp?token=<your-bearer-token>
     ```
     *(Or with custom external port: `https://<your-domain>:8443/mcp?token=<your-bearer-token>`)*
   - **Authentication:** Select **`None`** *(Because the API key is passed directly in the URL)*
   - **Transport:** Select **`Streamable HTTP`**
4. Click **Add** / **Connect**. All 23 tools will appear in your Claude chat sessions!

---

### 2. ChatGPT (Desktop MCP & Custom GPTs)

#### A. ChatGPT Desktop App (Developer Mode / MCP)
In the ChatGPT Desktop app (macOS / Windows), enable **Developer Mode** or configure MCP settings:
```json
{
  "mcpServers": {
    "ubuntu-server": {
      "url": "https://<your-domain>/mcp",
      "headers": {
        "Authorization": "Bearer <your-bearer-token>"
      }
    }
  }
}
```
*Alternatively, you can provide the direct authenticated URL:*
```text
https://<your-domain>/mcp?token=<your-bearer-token>
```

#### B. Custom GPTs / OpenAI Actions
In OpenAI ChatGPT Custom GPT editor:
- **Authentication:** API Key (Bearer) -> `<your-bearer-token>`
- **Server Endpoint:** `https://<your-domain>/mcp`

---

### 3. Claude Desktop / Cursor / VS Code

Add the following to your `claude_desktop_config.json` (or Cursor / VS Code MCP settings):

```json
{
  "mcpServers": {
    "ubuntu-server": {
      "url": "https://<your-domain>/mcp",
      "headers": {
        "Authorization": "Bearer <your-bearer-token>"
      }
    }
  }
}
```

*Config file locations:*
* **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
* **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
* **Linux:** `~/.config/Claude/claude_desktop_config.json`

## 🔒 Security Model

1. **Root Isolation & Protection:**
   The MCP server binds strictly to `127.0.0.1:<PORT>` and is never exposed directly to the public internet.
2. **Reverse Proxy Layer:**
   Nginx acts as the gatekeeper on port 443, enforcing TLS 1.2/1.3 with Let's Encrypt certificates.
3. **Cryptographic Authentication:**
   Every request must supply the 64-character Bearer token either via `Authorization: Bearer <TOKEN>` header or `?token=<TOKEN>` query parameter. Unauthorized requests are immediately rejected with `401 Unauthorized`.
4. **Token Security:**
   The token is stored in `/etc/ctrlmcp/token` with `600` permissions (readable solely by `root`).
5. **DNS Rebinding & CORS Protection:**
   CORS preflight requests (`OPTIONS`) are handled securely with proper response headers, allowing browser access from approved clients like `claude.ai`.

## 🌍 الدليل باللغة العربية (Arabic Guide)

**CTRLMCP** هو خادم MCP متكامل ومجهز بالكامل للعمل على خوادم أوبونتو (Ubuntu) بصلاحيات الـ **Root** الكاملة. يتيح لك ربط السيرفر مع الذكاء الاصطناعي (مثل **Claude** و **Cursor**) لإدارة السيرفر بالكامل من خلال الشات.

### التثبيت بأمر واحد:
نفّذ هذا الأمر على السيرفر بصلاحيات الـ Root:
```bash
curl -fsSL https://raw.githubusercontent.com/ahmadElsharawy/CTRLMCP/main/install.sh | sudo bash
```

### 1. طريقة الربط مع كلود ويب (Claude Web):
1. ادخل إلى **Claude.ai** ← اضغط على صورتك أو اسمك ← **Customize** ← **Connectors**.
2. اضغط على **"Add custom connector"**.
3. ضع البيانات كالتالي:
   - **الرابط (URL):**
     ```text
     https://<your-domain>/mcp?token=<your-bearer-token>
     ```
   - **نوع المصادقة (Authentication):** حدد **`None`** *(لأن التوكن مدمج في الرابط كـ API Key)*.
   - **بروتوكول النقل (Transport):** اختر **`Streamable HTTP`**.
4. اضغط **Add** أو **Connect** وسيتم ربط جميع الـ 23 أداة مباشرة داخل الشات!

### 2. طريقة الربط مع شات جي بي تي (ChatGPT):
* **تطبيق شات جي بي تي للكمبيوتر (ChatGPT Desktop - وضع المطورين MCP):**
  في إعدادات التطبيق أو ملف الإعدادات ضع الرابط:
  ```text
  https://<your-domain>/mcp?token=<your-bearer-token>
  ```
  أو استخدم كود الـ JSON مع الـ Header:
  ```json
  {
    "mcpServers": {
      "ubuntu-server": {
        "url": "https://<your-domain>/mcp",
        "headers": {
          "Authorization": "Bearer <your-bearer-token>"
        }
      }
    }
  }
  ```
* **في Custom GPTs (Actions):**
  - عنوان الـ Server: `https://<your-domain>/mcp`
  - نوع المصادقة (Auth): API Key (Bearer) وتضع التوكن الخاص بك.

### 3. طريقة الربط مع كلود ديسكتوب و كورسور (Claude Desktop & Cursor):
ضع كود الـ JSON في ملف `claude_desktop_config.json` أو إعدادات Cursor وسيتم الاتصال فوراً.

* **`[2]`** ✍️ لكتابة توكن مخصص من اختيارك (مثل `21123123`) وتحديث كل الروابط فوراً.
* **`[3]`** 🔄 لإعادة تشغيل السيرفر.
* **`[4]`** 📜 لعرض السجلات المباشرة (Live Logs).
* **`[5]`** 📋 لتحديث الشاشة.
